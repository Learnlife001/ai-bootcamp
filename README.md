# Chigozie G. Okuma AI Portfolio

A motion focused personal portfolio for Chigozie G. Okuma, an AI Builder, Full Stack Developer and Automation Specialist based in Germany.

## Live portfolio

[Open the portfolio](https://cj.greglabs.nl)

The portfolio is deployed on Vercel and served through the custom domain `cj.greglabs.nl`.

2. Services and technical capabilities

React, TypeScript, Next.js, Tailwind CSS, Framer Motion and Lucide React.
